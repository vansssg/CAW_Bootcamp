# CAW UPSK Engineering Bootcamp

## Overview

This repository contains my work and artifacts from the **CAW UPSK Engineering Bootcamp**, a practical software engineering program focused on developing an engineering mindset through real-world workflows.

The bootcamp focused on moving beyond just writing code and learning how engineers approach software development:
- Understanding requirements
- Making technical decisions
- Breaking down complex problems
- Designing scalable systems
- Debugging and improving solutions
- Using AI effectively as an engineering partner
- Communicating technical decisions clearly

# Engineering Workflow

The bootcamp followed a structured engineering cycle:
CONTEXT → DECIDE → BUILD → VERIFY → BREAK → FIX → REFLECT


### Context
Understanding the problem, requirements, constraints, and expected outcomes before implementation.

### Decide
Making engineering decisions by evaluating trade-offs, dependencies, risks, and possible approaches.

### Build
Creating solutions, specifications, designs, and implementation plans based on the decisions made.

### Verify
Validating whether the solution satisfies the defined requirements and acceptance criteria.

### Break
Testing robustness by considering unexpected scenarios, failures, and changing requirements.

### Fix
Improving the solution based on findings and adapting to new constraints.

### Reflect
Documenting learnings, evaluating decisions, and identifying improvements.
