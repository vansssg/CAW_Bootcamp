STEP 3: BUILD

Code generation starts now.

‍​‍​​​​​​​Minimum analytics behavior:

- On redirect, record a click event with:
  - link id
  - timestamp
  - user agent + referrer (if present)
  - ip hash (privacy)
  - (Decision) retention window: record as decisions.module_07.retention_days = <int> (example: 30)
- Add a protected analytics read endpoint (owner-scoped), minimum:
  - click count for one link over a time window
  - optional: last clicked timestamp
  - Recommended endpoint shape (adjust only if you have a strong reason):
    - GET /<links-route>/<LINK_ID>/analytics?from=2000-01-01&to=2100-01-01

If async_queue:

- enqueue a job on redirect
- worker processes job and writes click event
- configure retries
- ensure job is idempotent (duplicate jobs don’t double-count)
- add a purge mechanism for retention (repeatable job / scheduled task / admin-only command)

- Two redirects result in two click events counted (sync) or queued+processed (async).
​‌‌‌‌​‌‌‌‌- Replaying the same job payload does not double-count.
