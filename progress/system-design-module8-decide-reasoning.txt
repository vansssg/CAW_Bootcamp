A: db_native. Module 02 is PostgreSQL. Owner-scoped substring/tag/sort must be fresh after POST /links; a search-engine replica would lag (eventual consistency) on a 10k-link admin list. Fuzzy matching is not a product requirement. Elasticsearch/Meilisearch adds a cluster we cannot operate: Docker engine is down, Redis localhost:6379 is down. Tradeoff: ILIKE can scan; CONTEXT cap page_size=50 and allowlisted sort. While 5432 is down, in-memory owner filter is the same contract, not a fake ES. B (search_engine) would be right for fuzzy/typo search across millions of docs with an indexer we actually run.
