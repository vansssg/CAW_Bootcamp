# AI-Augmented Engineering Module 05 DECIDE

CLI is A|B. Recorded **A refine_first**.

Invitation handlers already matched this app (in-memory like `links`, `X-API-Key`, integer ids). IDOR, email regex, and rollback were surface: each probe line moved without rewriting the store. Restart-early would have thrown away a working `teams`/`memberships` map to re-prompt the same FastAPI shape.

Tradeoff: A spirals if we misread a structural miss (NOTIFY-from-INSERT, invites-on-Link). Safety rail: if two targeted prompts do not move measured statuses, new conversation with a different approach — not a fifth patch on `persist_invitation_sql`. Restart cost is a new prompt, not lost learning. Refine cost on a wrong foundation is review time plus polluted context.
